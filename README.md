# NEMO - Mental Health Chatbot

NEMO is an AI-powered chatbot designed to provide mental health and emotional support to students. It uses Google's Generative AI model, `gemini-1.5-flash`, to engage in meaningful conversations.

## Features
- **AI-driven chatbot** for mental health support.
- **User-friendly web interface** with an interactive chatbox.
- **Real-time conversation** with chat history.
- **Animated UI elements** including GIFs for a better user experience.
- **Secure API key handling** using `.env` file.
- **Responsive design** for desktop and mobile users.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS, JavaScript
- **AI Model:** Google Generative AI (`gemini-1.5-flash`)
- **Styling:** CSS (custom styles)
